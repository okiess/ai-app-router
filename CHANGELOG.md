# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-27

### Added

- Initial release of `aiar` CLI.
- Config-driven tool registry with TOML files.
- Tool types: `cli`, `webapp`, `api`.
- Commands: `list`, `show`, `resolve`, `which`.
- Human-readable and JSON output.
- Fuzzy tag matching with confidence scores.
- `add` command to create and update config entries.
- Interactive `add -i` mode.
- Agent skill documentation (`SKILL.md`).
