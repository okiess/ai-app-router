# Contributing

Contributions are welcome.

## Getting started

```bash
git clone https://github.com/okiess/ai-app-router.git
cd ai-app-router
cargo build
```

## Quality checks

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
```

## Adding a feature

1. Open an issue to discuss the change.
2. Fork the repository and create a branch.
3. Keep the change focused and add tests where possible.
4. Update `README.md` and `SKILL.md` if user-facing behavior changes.
5. Submit a pull request.
